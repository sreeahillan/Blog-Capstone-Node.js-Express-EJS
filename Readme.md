# 📝 Blog Application

> A clean, responsive, and fully functional blogging platform built using **Node.js**, **Express.js**, and **EJS**.

---

## 🌟 Features

- ✍️ **Create Posts:** Draft and publish new blog posts effortlessly.
- 📖 **Read & Browse:** View all published posts directly from the homepage.
- ✏️ **Edit & Update:** Easily edit existing blog posts in real-time.
- 🗑️ **Delete Posts:** Remove posts with a single click.
- 🎨 **Responsive UI:** Clean, minimalist design that looks great on mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Templating Engine:** EJS (Embedded JavaScript)
- **Styling:** CSS3 / HTML5
- **Package Management:** npm

---

## 🚀 Getting Started

Follow these instructions to get a local copy up and running on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

```bash
node -v
npm -v

Installation
Clone the repository:

Bash
git clone [https://github.com/sreeahillan/Blog-Capstone-Node.js-Express-EJS.git](https://github.com/sreeahillan/Blog-Capstone-Node.js-Express-EJS.git)
Navigate into the project directory:

Bash
cd Blog-Capstone-Node.js-Express-EJS


Install the dependencies:


Bash
npm install


Start the application:

Bash
npm start
# or
node server.js
Open in your browser:

Navigate to http://localhost:3001 (or the port specified in your console).
